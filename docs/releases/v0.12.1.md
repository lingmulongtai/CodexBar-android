# CodexBar for Android v0.12.1

Liquid Glass receives LastWave-inspired refinements and a fixed header with provider ordering. Install **CodexBar-Android-v0.12.1.apk** over the existing app. Android version code **38** preserves the production signing identity and existing settings.

- **Fixed headers:** usage, trends, connections and settings show a bold title in a rounded glass header. The usage header keeps the refresh status visible.
- **Inline provider ordering:** use the header action, hold and drag a service card, then tap Done. The saved order updates as you move items; reset restores automatic ordering. The finish action remains accessible while scrolling. Material 3 Expressive also has the header action.
- **Refined glass surfaces:** directional edge lighting, spring action feedback and grouped provider rows complement the existing daily photography. The leading quota uses its provider color and reset times remain readable on narrow screens.
- Saved connections, Android and Windows acquisition modes, widgets, companion behavior and update endpoints are retained. Companion packages carry matching v0.12.1 metadata.

## Verification and limits

The previous implementation validation passed 445 unit tests (443 passed, 2 skipped), lint with 0 errors and 139 warnings, and debug assembly. An Android API 36.1 emulator exercised inline drag, automatic reset, Done, Back and edge scrolling in Japanese at 130% font size, and the Material 3 ordering flow. The light and dark dashboard and Trends stopped rendering at rest after scrolling. These are emulator checks, not physical-device acceptance. Android 11/12 fallback rendering and OEM-specific behavior remain unverified on physical devices.

The release workflow builds the signed APK/AAB, checks the pinned production signer, smoke-tests the signed app and companion packages, and publishes checksums, SBOMs and provenance attestations. See [implementation notes](../liquid-glass-glisse.md) for the design and upstream review.
