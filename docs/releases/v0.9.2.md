# CodexBar for Android v0.9.2

This release focuses on a dense, customizable home-screen widget at **347 × 69dp**, a compact Usage overview, and optional Devin monitoring. Existing connections and widget selections are retained.

## Widget studio

- Choose ten different layouts: Ledger, Inline meters, Columns, Tiles, Rings, Segments, Vertical, Focus, Dual windows, and Reset first.
- Show Codex, Copilot, and Claude together at 347 × 69dp. Remaining quota is the primary number; a second quota window and time to reset share the available width. The most constrained window is selected across the cached data.
- Adjust background RGB and opacity, each provider's accent color, light/dark text, corner radius, text size, provider order, and secondary-window visibility. The default is translucent gray. Appearance is saved per widget.
- Preview actual cached data using the same RemoteViews renderer as the launcher. Preview wallpaper is illustrative; it is not a blur of the real wallpaper.
- Countdown labels are recomputed at each widget refresh or resize, not every second. Freshness is available in Ledger and column layouts; pace/reset advice appears where taller layouts have room. Very narrow widgets prioritize provider and remaining percentage; larger text can reduce the number of visible providers.
- Keep the v0.9.1 bounded renderer, immediate cached fallback, per-widget update serialization, diagnostics, and privacy redaction. Unknown or unbounded quotas no longer become a false 100% remaining.

## Usage screen

A fixed small top bar replaces the large collapsing header. Symmetric cards show two quota windows and reset times, with telemetry, history, reset credits, and detailed guidance available after tapping. Two or three connected providers fit on a typical phone screen at default text size; scrolling remains available for more providers, errors, and accessibility settings.

## Devin and Claude

Devin supports a read-only **organization consumption** connection using a `cog_` key and organization ID. The key needs `ViewOrgConsumption`. The app shows ACUs consumed over the last 30 days across Devin products; daily boundaries use 08:00 UTC. The API does not expose subscription quota or remaining credit, so no remaining percentage is invented. See the [official API](https://docs.devin.ai/api-reference/v3/consumption/organizations-consumption-daily).

Claude Desktop users can keep using the desktop app. Sign the official Claude Code CLI into the same Pro/Max subscription once, finish setup from the home directory, then launch the Claude companion and pair it in Android Connections. The companion rejects **Showing last-known usage** readings rather than stamping old data as fresh. See the [setup guide](https://github.com/lingmulongtai/CodexBar-android/blob/v0.9.2/companion/claude/README.md).

## Install

Install `app-release.apk` over v0.9.1 without uninstalling. Open the existing widget's settings to choose a layout and colors. Companion archives are version-aligned with the app.
