# CodexBar for Android v0.14.0

This release adds a customizable GitHub dashboard and refines the Liquid Glass navigation. Install **CodexBar-Android-v0.14.0.apk** over the existing app; version code **43** uses the pinned production signing identity and retains existing app data.

- **GitHub dashboard:** sign in to view your profile, followers, publicly starred repositories, contribution calendar, commit periods, and activity overview. Open repositories and sort the available list by update, stars, name, or available contribution activity.
- **Private contributions:** the GitHub App reads metadata for repositories you choose to share. A separate OAuth authorization requests `read:user` for profile contributions. Initial setup guides you through both authorizations; neither requests repository write access. Device codes can be copied, and temporary network failures are retried while a code remains valid.
- **Personal widgets:** edit the dashboard directly, long-press to reorder, add repository shortcuts, and resize the calendar continuously or choose repository-card sizes. Widget arrangements are stored per account on the device.
- **Liquid Glass:** settings are available in every tab header, the GitHub edit action sits beside them, settings transitions match the horizontal tab motion, and navigation labels refract with the lens while retaining their original size.
- Existing connections, Android and Windows acquisition modes, widget settings, update URLs and companion workflows are retained. Shared PC history, spend and remote settings require Windows v0.71.0 or later.

## Verification and limits

The owner reviewed the Liquid Glass UI, GitHub dashboard and authorization flow on a physical Android device using a separate preview installation. The production release workflow builds and smoke-tests the signed APK, checks its pinned signer, and publishes checksums, SBOMs and provenance. Repository counts and rankings reflect the repositories and activity the granted permissions allow; GitHub contribution counts follow GitHub profile rules and need not equal raw repository commit totals.
