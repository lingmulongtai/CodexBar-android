# CodexBar for Android v0.9.5

This release fixes removing disconnected providers from widgets and adds reset alerts and an on-device activity history.

## Widgets after disconnecting

- Remove Antigravity or any other saved provider from an existing widget without reconnecting it first. Disconnected selections remain visible in the editor with their connection status.
- Remove the last provider and save an empty widget. Reopening the editor preserves that deliberate empty selection and the widget's appearance settings.
- New widgets still require a connected provider to be selected.

## Reset alerts and history

- Enable **Settings → Notifications → Reset alerts** independently of the persistent notification.
- Receive alerts after a successful refresh detects a quota-window renewal, an increase in available Codex resets, or a reset expiring within 24 hours.
- View and clear reset history in provider details: detected dates, previous reset boundaries, balance increases/decreases, and expiry reminders. History is limited to 100 events per provider and 90 days, excluded from Android backups, and cleared when disconnecting or replacing an account.
- Duplicate and overlapping refreshes do not repeatedly report the same changes. Privacy settings also cover reset alerts and immediately remove previously posted alerts when changed.

The first successful refresh establishes a baseline. History records observed changes, not a complete server redemption log: a balance decrease can mean use or expiry, and changes between updates can be missed. Notification permission is required; background and network delays can postpone alerts.

## Gemini and desktop companions

- Identify Gemini CLI as the existing quota source, distinct from Google's Gemini Windows and web apps. Open Gemini Apps from the connection card to check its **Settings → Usage Limits** screen.
- Automatic Gemini Apps usage collection is not supported in this release; no exposed quota API or local export interface was found in the inspected Windows app.
- The Gemini companion supports the current CLI `/model` quota view and pauses background retries until interactive sign-in and folder trust are complete. Use Gemini CLI 0.61.0 or newer.
- The Antigravity companion reads the IDE's reported weekly and five-hour model-group windows. The source checkout also includes the unified Windows Control Center; follow its [setup guide](https://github.com/lingmulongtai/CodexBar-android/blob/v0.9.5/companion/windows-control-center/README.md).

## Update and verification

Install **app-release.apk** over the existing app without uninstalling to preserve saved connections and widget configuration. The release retains the established production signing identity and uses version code **30**. Matching individual companion archives are included; preserve their private pairing files when updating.

Local checks passed 374 Android unit tests, lint and debug assembly. Android API 36.1 emulator checks covered removing disconnected widget providers, empty-widget persistence, reset alert contents with the persistent notification disabled, redaction, privacy cancellation and disabled alerts. Fresh screenshots use demo data only; see the [capture notes](https://github.com/lingmulongtai/CodexBar-android/blob/v0.9.5/docs/images/releases/v0.9.5/README.md). Physical-phone, Niagara Launcher and Samsung Now Bar acceptance remain separate from emulator validation.

The PR pipeline checks Android and the individual companions. Before publication, the tag workflow builds signed APK/AAB files, verifies the pinned certificate, cold-starts the signed APK on Android, and publishes checksums, SBOMs and build provenance.
