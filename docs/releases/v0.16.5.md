# CodexBar for Android v0.16.5

- **Liquid Glass navigation.** An unselected tab switches when you lift your
  finger. Sliding horizontally moves the lens with your finger. Holding the
  selected tab expands the lens above and below the bar, including with gesture
  navigation enabled.
- **Settings.** About CodexBar places the transparent app mark alongside the
  version and build number. Icons identify the project links, release and update
  actions, notifications, background refresh, wallpaper, haptics, language,
  privacy, and developer controls.

Install **CodexBar-Android-v0.16.5.apk** over the existing stable app to retain
its data. The Android version code is **50**. The bundled desktop companions
carry matching version metadata and their runtime code is unchanged.

The tab gestures and Settings layout were accepted on a Galaxy S25 Ultra
running the preview of these changes. Release screenshots show the v0.16.5
debug build on an API 35 emulator with synthetic data.

Read-only upstream main checked at
`1811d1fe032fd4a80240fd6bc5d04cee649a0afb`. The fork already includes that commit.
