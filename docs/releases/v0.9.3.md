# CodexBar for Android v0.9.3

This update makes provider identities and display order clearer, adds two dense widget layouts, and fixes missing Claude weekly usage.

## Icons and display order

- Replace generic service symbols with first-party artwork for all 19 providers. Multicolor marks retain their original colors in both themes. [Artwork sources](https://github.com/lingmulongtai/CodexBar-android/blob/v0.9.3/docs/provider-icons.md).
- Open **Usage → Reorder / 並び替え** to move providers up or down. The chosen order survives refreshes and restarts. Automatic ordering can be restored.
- Widget ordering now has its own numbered **Display order / 表示順** card, with both up/down controls and a live preview. Each widget keeps its own order.

## Two more widget templates

Existing templates keep their numbers and appearance. At **347 × 69dp**, the new layouts show Codex, Copilot and Claude together:

- **11 · Dual Segments / 横2枠セグメント**: template 9's provider rows and side-by-side quota windows, with segmented bars.
- **12 · Stacked Segments / 縦2段セグメント**: template 6's provider columns, with a separate segmented bar for each quota window.

Single-window providers still show one bar. Secondary-window visibility, background transparency, custom colors and privacy settings remain available. Percentages show remaining quota; reset countdowns update on refresh or resize.

## Claude companion

- Use a dedicated `~/.codexbar/claude-workspace` for the official Claude CLI's one-time setup and trust confirmation.
- Reconstruct cursor-based terminal redraws so unchanged weekly labels and their updated values are retained.
- Parse reset dates within each quota window so the 5-hour and weekly limits are both available.
- Document binding to a numeric Tailscale address for pairing across different networks, including when the PC is the phone's exit node. [Setup guide](https://github.com/lingmulongtai/CodexBar-android/blob/v0.9.3/companion/claude/README.md).

## Install and verification

Install **app-release.apk** over v0.9.2 without uninstalling to keep connections and widget settings. If updating a PC companion, extract its matching v0.9.3 archive, stop the old process and use the updated launcher; preserve the private configuration under `~/.codexbar`. Existing Claude sign-in and pairing keys remain compatible.

The implementation passed 329 Android unit tests and 28 native widget-host cases, including all 12 templates, privacy redaction and narrow sizes. Fresh release captures and the validation boundaries are documented [here](https://github.com/lingmulongtai/CodexBar-android/blob/v0.9.3/docs/images/releases/v0.9.3/README.md). Emulator evidence does not establish acceptance on every physical device or Niagara Launcher configuration.
