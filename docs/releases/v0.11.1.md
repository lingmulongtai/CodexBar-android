# CodexBar for Android v0.11.1

Liquid Glass now follows the refractive surfaces and responsive controls of [Glisse](https://glisse.kelvinzhang.com/) by Kelvin Zhang. Install **CodexBar-Android-v0.11.1.apk** over the existing app. Version code **36** retains the production signing identity and saved connections; no re-pairing is required.

- **Native glass lenses:** Android 13+ bends the live backdrop along rounded edges, with subtle colour dispersion and specular highlights. Foreground text and icons stay sharp. Android 12 uses backdrop blur; older Android versions retain opaque, readable surfaces.
- **A softer backdrop and glass cards:** the overview and service list sit over a light or dark gradient. Cards sample a separate background-only layer, including in the tablet two-pane layout, without sampling themselves.
- **Responsive controls:** floating tabs and the refresh button lift like lenses while pressed. History/Spend uses a glass segmented track; Settings switches use green tracks and glass thumb highlights. Native switch behavior, selected-state announcements and visible keyboard focus are retained.
- **No continuous idle redraw:** separate source/consumer graphics layers preserve the previous rendering-loop fix. Light and dark usage/spend screens stopped rendering after scrolling in the local emulator checks.
- Material 3 Expressive and Instrument remain available. Acquisition modes, encrypted connections, provider order, widgets, reset alerts, PC history/spend, signer, update endpoints and release workflow are retained. Shared PC history/spend/settings require Windows v0.71.0 or later.
- The four companion archives use the matching **v0.11.1** version. Their acquisition behavior is unchanged in this release.

## Verification and limits

Strict local Android unit tests, lint and debug assembly passed: **435 tests, 433 passed, 2 skipped, no failures/errors**. Lint has **131 warnings and no errors**. On the final Glisse implementation, the five-second idle checks measured light dashboard 1/0 frames and Spend 0/0 (initial/after-scroll); dark dashboard 0/0 and Spend 5/0. The allowed threshold is eight occasional frames, rejecting sustained drawing. A native switch state transition and navigation to Trends were also exercised; no app crash was recorded. [Implementation and rendering details](../liquid-glass-glisse.md)

The existing tag workflow builds the signed APK/AAB with strict dependency verification, compares the APK signer to the pinned production certificate, launches the signed APK through its resolved launcher entry, opens Connections by deep link, verifies the four packaged companions, generates SBOMs/checksums and attests the release artifacts before publication. CI status and provenance identify the exact build; local debug checks alone are not a claim that the signed release has passed these gates.

Physical phones/tablets, OEM launcher behavior, battery impact and Android 12 / Android 11 fallback rendering remain separate acceptance checks. The website demo is a visual reference; this is a native Compose adaptation, not pixel-for-pixel Safari/iOS rendering.

Read-only Android upstream `hyunnnchoi/CodexBar-android` `main` was checked at `1811d1fe032fd4a80240fd6bc5d04cee649a0afb`. No upstream-only commits were pending, so no compatible update or incompatible deferral was omitted.
