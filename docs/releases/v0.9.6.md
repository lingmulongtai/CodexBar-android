# CodexBar for Android v0.9.6

Receive usage collected by **Win-CodexBar Mobile** on Windows without entering provider tokens again on the phone. This release adds the compatible Android receiver; the Windows app is maintained in the separate [Win-CodexBar fork](https://github.com/lingmulongtai/Win-CodexBar).

## Connect Windows once

Enable **Settings → Advanced → Android sharing** in Win-CodexBar Mobile, select the PC's private LAN or Tailscale IPv4 address, and copy its pairing code. Paste it into **Connections → Win-CodexBar** on Android. Choose which supported services should receive their usage from Windows.

The Windows app must remain running and reachable. Android fetches during normal refreshes, so alerts are subject to refresh intervals and background scheduling. For detailed setup, see the [Windows guide](https://github.com/lingmulongtai/Win-CodexBar/blob/main/docs/android-sharing.md).

## Source and history safeguards

- Saved phone credentials are preserved. Turn a Windows service off or disconnect Windows to return to its saved phone source.
- Pairing details are encrypted with Android Keystore; authenticated requests and AES-256-GCM encrypted responses contain usage observations rather than provider credentials or raw account identity.
- Replacing or removing a source clears its cached display and history. An older in-flight refresh cannot republish usage after the source changes.
- Failed desktop fetches remain errors. Unknown counters are never turned into zero. Older observations show their actual age; stale observations do not produce fresh reset alerts or pace history.
- Reset and quota history remain scoped to the observed account. Known Codex reset-credit values are supported through the Windows feed.
- Windows-sourced services are eligible for widgets, notifications and the quick settings tile. Existing disconnected-provider widget editing from v0.9.5 remains supported.

**Gemini in this integration is Gemini CLI. Google Gemini Apps / the Google Gemini Windows app's usage display is not automatically collected.**

## Installation and validation

Install **app-release.apk** over the existing Android app without uninstalling. Version code **31** retains the established production signing identity and stored connections. The Windows portable Preview is a separate, unsigned executable; it does not use the upstream Windows project's signing certificate.

Validation includes Rust and Android authentication vectors, source-switch and history tests, an actual native Windows-to-Kotlin exchange, and Android API 36.1 emulator captures using synthetic quotas. The debug capture activities are excluded from the signed release. Physical-phone, Niagara Launcher, Samsung Now Bar and live-account acceptance remain separate checks.

Release assets include signed APK/AAB files, companion archives, SBOMs, screenshots, SHA-256 checksums, build provenance and artifact attestations.
