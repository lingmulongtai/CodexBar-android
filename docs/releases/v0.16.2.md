# CodexBar for Android v0.16.2

This patch connects the app's pages into one finger-following track, adds provider ordering to Trends and Connections, and adds optional light haptics. Install **CodexBar-Android-v0.16.2.apk** over the existing app; version code **47** retains the pinned production signing identity and existing app data.

- **Connected pages:** Usage, Trends, Connections and GitHub move together as adjacent pages. Reverse a held swipe to cancel it. Tab taps move along the same track, including intermediate pages. The glass header stays pinned and changing header height no longer changes the page's vertical origin.
- **Settings return:** Settings and Dev settings retain their originating tab. Back or tapping that tab returns to it, including Back during entry. Inactive pages do not intercept Back, show dialogs or keep a Dev preview active.
- **Provider ordering:** Trends and Connections now reuse Usage's Reorder/Done and long-press controls. Each screen saves its own order; History and Spend share the Trends order. Search filters and temporarily disconnected providers retain their positions. Expanded Windows connection panels survive scrolling out of view.
- **Optional haptics:** Settings → Haptic feedback defaults on and survives restarts. Tab/segmented presses and switch/slider lens lifts request one light pulse. Holding, dragging and release do not keep pulsing. Turning it off also silences reorder feedback. Android's system haptic settings and hardware support still apply.
- **Launcher verification:** the published v0.16.1 APK already contains the approved blue C/three-bar/yellow-accent artwork. Its decoded image is identical to the source image, and a fresh install displays it correctly. v0.16.2 retains that artwork for the application, round icon and every installed launcher alias; a regression test checks the complete reference chain. A stale icon on a particular device was not reproduced or assigned a confirmed cause.

In-app downloads, saved connections, GitHub authorizations, widgets and acquisition modes are preserved. Shared PC history, spend and remote settings still require Windows v0.71.0 or later. See the [design contract](https://github.com/lingmulongtai/CodexBar-android/blob/v0.16.2/docs/liquid-glass-design-contract.md) and [in-app update guide](https://github.com/lingmulongtai/CodexBar-android/blob/v0.16.2/docs/in-app-updates.md).

## Verification and limits

Local Android validation completed 519 unit tests: 517 passed and two explicit opt-in Windows interoperability checks were skipped. The suite includes the added launcher reference-chain regression test. Debug lint and APK assembly passed. The release is gated by the complete CI test/lint/build suite and the production workflow's signed-APK startup checks, pinned signer verification, checksums, SBOMs and provenance.

Emulator validation covered nine Settings return paths (three originating tabs with selected-tab tap, Back and early Back), held swipe/reversal, provider dragging, and haptic setting persistence in both states across process termination. The installed stable v0.16.1 alias migrated from LauncherExpressive to LauncherLiquidGlass after leaving the app, while both resolved to the approved artwork. These checks do not establish the physical strength/feel of haptics or the state of a disconnected phone's launcher cache.

Read-only upstream main checked on 2026-11-04 at `1811d1fe032fd4a80240fd6bc5d04cee649a0afb`; there were no upstream-only changes to incorporate or defer.
