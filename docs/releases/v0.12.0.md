# CodexBar for Android v0.12.0

Liquid Glass gains held gestures, daily photography and a calmer reading layout. Install **CodexBar-Android-v0.12.0.apk** over the existing app. Version code **37** keeps the production signing identity and saved connections.

- **Hold and slide:** long-press the floating tab bar and move the glass lens to another tab. Releasing navigates once; cancelling restores the current selection. Glass switches follow a held drag and settle on release. Sliders retain native snapping, range accessibility and disabled-state handling, with glass thumbs and slim tracks.
- **Two designs:** choose Liquid Glass or Material 3 Expressive. The retired Instrument/Aurora setting moves to Expressive. A compatibility launcher alias keeps older Instrument installations launchable until the replacement icon is enabled.
- **Daily Unsplash backgrounds:** six curated landscapes rotate by local date without an API key. The last successful photo survives navigation, restarts and unavailable networks. Settings offers enable/disable, update status/date, manual refresh, photographer links and an optional encrypted personal Access Key for Editorial. Photographer and Unsplash attribution remain visible. No shared API key is embedded. [Photo sources, caching and API details](../daily-wallpaper.md)
- **A focused home overview:** the multi-provider concentric rings are replaced by a clear provider/window label, remaining percentage, slim meter and reset time. Provider-specific readings remain in the list.
- **Consistent glass controls:** settings, connection actions, language/provider selectors, filters, sliders and history/spend panels share the glass treatment. Inter typography, increased leading and more space around settings descriptions improve readability. Apple platform fonts are not bundled.
- **Glass charts:** history/spend panels use translucent surfaces, while spend bars use a soft gradient and rounded edges. Their values, missing-data handling and day selection are retained.
- Acquisition modes, encrypted provider connections, provider order, widgets, reset alerts, PC history/spend, signer and owned update endpoints are retained. Companion packages have matching **v0.12.0** metadata; acquisition behavior is unchanged.

## Verification and limits

Strict local dependency verification, Android unit tests, lint and debug assembly passed: **443 tests, 441 passed, 2 skipped, no failures/errors; lint 0 errors and 139 warnings**. The input verifier exercises actual held tabs, switches and sliders in LTR and RTL, tap navigation, cancellation, single callbacks and disabled switches. The final rendering verifier also rejected obscured/error-dialog surfaces and passed light dashboard 1/0, Spend 5/0; dark dashboard 4/0, Spend 4/0 frames over five seconds (initial/after-scroll). Input checks passed at 130% font scale in LTR and RTL. [Implementation and emulator evidence](../liquid-glass-glisse.md)

Real-key Editorial success, physical phones/tablets, OEM launcher behavior, battery impact and Android 12 / Android 11 fallback rendering remain separate acceptance checks. The keyless curated mode does not claim to show the latest Editorial feed. The older emulator showed system-app ANRs and Windows qemu crashes during development. Final checks used an isolated stable Emulator 37.2.13, preserving the original SDK. Capture dimensions and evidence are recorded with the images.

The tag workflow builds signed APK/AAB artifacts, checks the pinned production signer, launches the signed app, verifies packaged companions, and publishes checksums, SBOMs and GitHub provenance attestations. CI and released artifact evidence identify the exact source commit.
