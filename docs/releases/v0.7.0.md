# CodexBar for Android v0.7.0

This is a stable feature release, not a beta. It keeps the existing Material 3 experience while adding three complete visual alternatives, makes Codex reset allowance and history actionable, and ports the latest relevant provider work from the original macOS CodexBar.

## Four selectable design systems

- Keeps Material 3 as the default, including Android dynamic color.
- Adds Liquid Glass, WinUI 3, and Aurora as full-app styles rather than isolated card skins.
- Applies each style to app backgrounds, top-level surfaces, navigation, cards, shapes, elevation, borders, and provider accents in both light and dark appearance.
- Persists the selection locally and applies it immediately from Settings.

## Codex reset, history, context, and token insights

- Fetches the provider's reset-credit inventory and shows the available count, the next expiry, every dated expiry in details, and credits without an expiry date.
- Displays every provider-reported Codex quota window, including model-specific windows, without inventing a limit that the response omitted.
- Retains bounded local quota samples and draws usage-history sparklines on dashboard cards and full charts in details.
- Keeps pace forecasts and reset plans tied to the exact remaining amount and reset deadline.
- Adds an optional private Codex telemetry companion for the current context window, session tokens, input/cached-input/output/reasoning totals, daily token activity, and per-model totals.

The companion scans only bounded recent `~/.codex/sessions` data for `token_count` and model metadata. It never returns prompts, responses, file paths, working directories, session IDs, account tokens, or source files. Pairing requests are HMAC-authenticated and replay/rate-limit protected; snapshots are encrypted with AES-256-GCM and served only on a numeric private-network address. Subscription quota and reset credits continue to work directly from OpenAI when the companion is off.

## Latest upstream provider additions

- Adds Cline plan usage with provider-reported 5-hour, weekly, and monthly windows.
- Adds IBM Bob monthly Bobcoin usage and budget aggregation across visible teams, with strict `bob.ibm.com` regional-host validation.
- Adds Fireworks AI rated spend for the previous 30 days using a validated account slug and the fixed first-party billing endpoint.
- Brings the Android provider catalog to 18 supported services while retaining per-provider encrypted credentials, validation-before-save, redirect refusal, and logging-disabled credential traffic.

These additions follow the current relevant provider behavior from original CodexBar v0.49.3, adapted to Android's security and account-linking constraints rather than copying desktop credential stores.

## Release verification and artifacts

- Six screenshots were captured from the real Compose UI on an Android 16.1, 1080 × 2400 emulator with deterministic demo data; the screenshot Activity exists only in debug builds.
- The tag workflow verifies both Node.js companions, builds a minified signed APK and AAB, checks the pinned production signing certificate, and cold-starts the signed APK on an Android 16 emulator before publication.
- Release assets include `app-release.apk`, the AAB, both companion ZIPs, Android and companion CycloneDX SBOMs, all six screenshots, `SHA256SUMS`, build provenance, and GitHub attestations.
- The built-in stable-update prompt continues to select this repository's production-signed APK and ignores draft or prerelease builds.

## Install or update

1. Download `app-release.apk` from the assets below.
2. Optionally compare its SHA-256 digest with `SHA256SUMS`.
3. Install it directly over v0.6.0 to preserve encrypted provider connections, preferences, quota history, and widget configuration.
4. Open **Settings → Appearance → Visual style** to choose Material 3, Liquid Glass, WinUI 3, or Aurora.
5. Open **Connections** to add Cline, IBM Bob, or Fireworks AI.
6. For local Codex context/token insight, download `CodexBar-Codex-Telemetry-Companion-v0.7.0.zip`, follow its README, and pair it from the Codex connection card.
7. Gemini users should update to `CodexBar-Gemini-Companion-v0.7.0.zip` from this Release.

The APK is signed with the same production certificate as v0.6.0. A signature-conflict warning means the installed app came from a different signer; uninstalling erases local credentials and settings, so verify the APK source before doing that.

Quota history begins with samples collected by this app version. Local Codex context/token insight requires the companion and is separate from OpenAI subscription accounting.
