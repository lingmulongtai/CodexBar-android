# CodexBar for Android v0.11.0

Three complete designs, four-tab navigation and improved large-screen layouts. Install **CodexBar-Android-v0.11.0.apk** over the existing app. Version code **35** retains the production signing identity and saved connections; no re-pairing is required.

- Choose **Material 3 Expressive**, **Liquid Glass** or **Instrument** in Settings → Visual design. Each has its own header, overview, provider cards, navigation and launcher icon. Expressive uses bold readings and wave-shaped meters; Liquid Glass has floating navigation with a real blurred backdrop on Android 12+ and an opaque fallback on older versions; Instrument uses an always-dark, compact numerical layout.
- **Usage / Trends / Connections / Settings** form four tabs. History and Spend switch within Trends, and the last selected page is remembered during navigation. Tablets use a navigation rail or centered glass bar, adaptive card widths and a two-pane dashboard.
- Ordinary refreshes keep readings and navigation available. Per-provider activity and a completed/total count show progress. Tabs share their dashboard model and avoid redundant refreshes within one minute.
- **Review fix:** disconnecting, replacing an account or changing acquisition sources immediately clears the previous source's readings from Usage and Trends, even when a slow refresh is already running. Ordinary refreshes still retain their content.
- The launcher icon follows the selected design after leaving the app. Saved WinUI 3 selections move to Expressive; Aurora selections move to Instrument. Launcher behavior varies: shortcuts can be removed when their old icon entry is disabled.
- Phone/Windows acquisition modes, encrypted saved connections, provider order, widgets, reset alerts, PC history, reference costs/token charts and opt-in remote PC settings are retained. PC history/spend/settings require **Windows v0.71.0 or later**; the current Windows v0.71.1 is compatible.
- README and the website now describe the same three designs and use current emulator captures.

## Verification

Local validation on Windows completed with strict Gradle dependency verification: `:app:testDebugUnitTest`, `:app:lintDebug` and `:app:assembleDebug` passed. **435 tests: 433 passed, 2 skipped, no failures.** The two opt-in native Windows interop tests were not rerun in this release review. Lint reported **130 warnings, no errors**; this is not a claim that all existing warnings have been resolved. `ReleaseVersionConsistencyTest` passed with synchronized app/companion versions, current notes and ten fresh PNG captures. The static website validator passed.

The ten captures use the v0.11.0 debug APK (version code 35), at 1080×2400 / 420dpi and 2560×1600 / 240dpi. All three phone/tablet dashboards, Liquid Glass dark mode, History, Spend and separate Gemini Apps/CLI entries rendered with no app crash. They use synthetic data, not a live account connection. The production release workflow additionally checks the signer, launches the signed APK through its default launcher icon and opens Connections by deep link.
