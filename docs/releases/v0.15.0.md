# CodexBar for Android v0.15.0

This release expands the GitHub dashboard with native Liquid Glass profile widgets and fixes horizontal navigation. Install **CodexBar-Android-v0.15.0.apk** over the existing app; version code **44** retains the pinned production signing identity and existing app data.

- **Profile widgets:** add Achievements, Year in review, Tech stack and an ASCII-style Portrait from the header's Edit → + menu. Existing long-press widget ordering and continuous calendar resizing remain available.
- **Achievements:** show confirmed public GitHub badge artwork and tiers, alongside separately labeled local achievements derived from activity. Public badges that are not shown are not treated as unearned. Progress uses a confirmed tier's lower bound when a public count cannot represent private activity.
- **Year in review:** view contributions, best day, longest/current streak, active days, busiest weekday and monthly totals over the last 365 days. The Today / This week / This month / This year commit periods retain their existing meanings.
- **Contribution calendar:** a native staggered entrance, blue intensity levels, month labels, selection outlines and a legend bring the profile calendar into the app's glass design. Resizing does not restart the entrance animation, and platform animation-duration settings are respected.
- **Tech stack and Portrait:** the public profile README's first `skillicons.dev` icon list supplies the authored stack and its second list supplies learning technologies. Supported logos are bundled native vectors; unknown technologies use text. The portrait is rendered locally from the public avatar.
- **Pinned repositories:** collect selected repositories in one widget, with at most two cards per row. Cards omit the owner prefix and retain visibility, description, language and stars. Existing individual pins migrate in order into one account-specific group. Use its Edit action to search and select repositories.
- **Navigation:** the settings action no longer fades on tab entry. The header is measured before placing the page content, keeping body movement horizontal while the header height changes, including navigation to GitHub and Settings.

The additional public profile requests do not require another login and do not send account tokens. Existing private contribution authorization, saved connections, phone/Windows acquisition modes, update URLs, widgets and companion workflows are retained. Shared PC history, spend and remote settings require Windows v0.71.0 or later.

## Verification and limits

Local validation covered header geometry, pin migration/account isolation, rolling statistics/streaks, badge/README parsing and tokenless public requests. The full debug suite completed with 487 passing tests and two explicit opt-in Windows native interoperability tests skipped; lint and APK assembly passed. Emulator captures and transition frames were inspected. This iteration does not claim physical-device verification.

The production workflow builds and smoke-tests the signed APK, verifies the pinned signer, and publishes checksums, SBOMs and provenance. Public achievements depend on GitHub's public HTML and fall back to unavailable if its markup changes. The stack widget needs a supported authored README list; repository counts and private activity remain limited by granted permissions and GitHub profile rules.

Read-only upstream main was checked at `1811d1fe032fd4a80240fd6bc5d04cee649a0afb`; there are no upstream-only commits to incorporate or defer.
