# CodexBar for Android v0.16.6

- After a horizontal drag on the Liquid Glass tab bar, the lens shrinks and
  settles into the target tab from the release position while the page scrolls.
- Liquid Glass containers default to 8 dp frost, 0.70 bend, 0.30 dispersion,
  0.15 edge shine, 1.40 saturation, 0.20 tint and 1.00 bend reach. The rim
  uses each component's own material. Saved container adjustments take priority.
  Resetting the group restores the new defaults.

Install **CodexBar-Android-v0.16.6.apk** over the existing stable app to retain
its data. The Android version code is **51**. The bundled desktop companions
carry matching version metadata.

The preview was accepted on a Galaxy S25 Ultra. The API 35 emulator checks
included dragging from Usage to Connections and verifying the container
defaults on a fresh install. The bundled gesture frames show the same UI code
before the version bump, using synthetic data.

Read-only upstream main checked at
`1811d1fe032fd4a80240fd6bc5d04cee649a0afb`. The fork already includes that commit.
