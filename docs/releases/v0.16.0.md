# CodexBar for Android v0.16.0

This release adds live developer controls for app animation and Liquid Glass materials. Install **CodexBar-Android-v0.16.0.apk** over the existing app; version code **45** retains the pinned production signing identity and existing app data.

- **Independent animation speed:** app-authored Compose motion uses its own duration scale, including when Android's animator-duration scale is set to zero. Open **Settings → Dev settings** to choose 0.25–3× speed or the 0.5× / 1× / 2× presets. Larger values mean faster motion. Dialogs, widget configuration and the language-selection settling time follow the same preference.
- **Live glass tuning:** independently adjust Cards (including Running out first), Header, Tab bar and Controls. Eight parameters expose frost, bend, dispersion, rim, edge shine, saturation, tint opacity and bend reach. Changes preview immediately and save when the gesture finishes.
- **Reliable local preferences:** saved settings survive process restart. Overlapping saves cannot replace a newer live draft, completed writes survive leaving the screen, and failed saves offer retry. Reset a surface group or all Dev settings to restore the original appearance.
- **Preserved layout:** glass tuning changes materials while retaining established positions, sizes, shapes, corner radii, touch targets and the nested-panel rendering rule. Connections, GitHub authorization, acquisition modes and widget preferences retain their existing behavior.

See the [Dev settings guide](https://github.com/lingmulongtai/CodexBar-android/blob/v0.16.0/docs/developer-settings.md) for parameter ranges and rendering limits. Shared PC history, spend and remote settings still require Windows v0.71.0 or later.

## Verification and limits

Local validation completed 500 tests: 498 passed and two explicit opt-in native Windows interoperability checks were skipped. Debug lint and APK assembly passed. Emulator measurements of a 400 ms tween remained approximately 421–447 ms at app speed 1× with Android scales 0×, 1× and 10×. App speed 2× measured 242 ms and 0.5× measured 879 ms. The actual coroutine context, child dialog timing policy, fast slider saves and persistence after process restart were checked. No physical-device verification is claimed for this iteration.

The production workflow builds and smoke-tests the signed APK, checks the pinned signer, and publishes checksums, SBOMs and build provenance. Android-owned permission prompts, launcher/window transitions and external apps continue to follow Android's settings. The isolated Compose window recomposer policy uses an internal API and must be revalidated when Compose is upgraded. Blur requires Android 12+ and refraction Android 13+; older devices keep the existing fallback rendering path. Some shader parameters require a live backdrop and nonzero bend.

Read-only upstream main was checked at `1811d1fe032fd4a80240fd6bc5d04cee649a0afb`; there are no upstream-only commits to incorporate or defer.
