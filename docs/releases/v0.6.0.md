# CodexBar for Android v0.6.0

This is a stable feature release, not a beta. It turns Codex reset data into a practical usage plan and carries the same recommendation from the dashboard to widgets and notifications.

## Reset-aware Codex guidance

- Shows the remaining allowance together with its exact reset deadline.
- Calculates a balanced hourly budget and, for longer windows, a daily budget from the current remaining allowance and time left.
- Converts usage pace into clear actions: use now, slow down, keep the current pace, save the final allowance for priority work, or meet the next timed checkpoint.
- Evaluates every Codex quota window returned by the provider, including short-term and weekly windows, without inventing a missing limit.
- Keeps the existing positive message when Codex does not return a short-term limit so the dashboard explains that the longer window is currently the useful constraint.

## Dashboard and at-a-glance surfaces

- Adds a Material 3 reset-plan banner to both dashboard cards and quota detail views.
- Localizes deadlines, balanced budgets, and action guidance in English and Japanese using the device time zone.
- Adds compact guidance to home-screen widgets and both persistent and user-started Live Update notifications.
- Uses the same immutable presentation snapshot on every surface so the number, deadline, and recommendation remain consistent.
- Suppresses reset planning whenever sensitive quota values are redacted.

## Safe update path

- Keeps the built-in update prompt enabled: the app checks this fork's latest stable GitHub Release when it opens.
- Compares stable versions numerically, ignores beta and draft releases, and accepts download links only from this repository's trusted HTTPS release path.
- Selects the production-signed `app-release.apk` asset when available and falls back to the trusted Release page.
- Installing the APK over v0.5.0 with the same production signer retains linked accounts, settings, quota history, and widget configuration.

## Verification

- Passes 221 unit and source-policy tests with no failures.
- Passes strict Gradle dependency verification, Android Lint, and debug APK assembly.
- Includes boundary tests for nearly exhausted, expiring, at-risk, on-track, missing, invalid, and expired quota windows.
- Verifies dashboard, widget, notification, localization, privacy-redaction, update-checking, and release-version contracts.
- The release workflow separately builds and verifies the production-signed APK and AAB, tests the Gemini companion, runs an Android 16 emulator startup smoke test, generates SBOMs and checksums, and publishes build provenance attestations.

## Install or update

1. Download `app-release.apk` from the assets below.
2. Optionally compare its SHA-256 digest with `SHA256SUMS`.
3. Install it directly over v0.5.0 to preserve encrypted local data and settings.
4. Open the Usage dashboard to see reset planning for each available Codex window.
5. Future stable releases will appear through the built-in update prompt the next time the app opens.
6. Gemini users should also update to `CodexBar-Gemini-Companion-v0.6.0.zip` from this Release.

The APK is signed with the existing production certificate. A signature-conflict warning means the installed app came from a different signer; uninstalling erases local credentials and settings, so verify the APK source before doing that.
