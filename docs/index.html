MOBILE CONNECT

取得はスマホでも、Windowsでも。

Win-CodexBar + Mobile Connectと接続すれば、PCの使用枠・トークン数・推定費用をスマホで確認できます。スマホで取得するモードと切り替えられ、接続情報と履歴は保持します。

Tailscaleは同じネットワークに接続するだけ。スマホのexit nodeは不要です。PCは起動したままにしてください。v0.9.8ではGemini Appsの現在・週間の使用率も表示でき、Gemini CLIとは別の項目です。スマホとタブレットは同じ接続コードで利用できます。

PRIVATE BY DESIGN

あなたの資格情報は、あなたの端末に。

CodexBar専用のホスト型バックエンドはありません。接続情報はAndroid Keystoreで保護され、検証に成功したあとだけ暗号化保存されます。

セキュリティ設計を読む ↗
01

Keystore暗号化

資格情報は端末固有の鍵で暗号化。バックアップや端末移行からも除外します。

02

固定された送信先

認証情報を任意のURLへ送らず、対象サービスの検証済みHTTPSホストだけを使用します。

03

オープンな実装

MITライセンス。アプリ、companions、リリース検証の実装をGitHubで確認できます。
