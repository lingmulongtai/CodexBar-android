# v0.16.4 screen references

These are real API 35 emulator captures of debug v0.16.4/code49, using synthetic
quota and GitHub data, not private accounts. The UI source matches this release.
The isolated Windows emulator 37.2.13 uses the host NVIDIA GPU. The debug fixture
activity is excluded from production builds.

The size matrix and interaction results are documented in
[`docs/adaptive-tablet-layout.md`](../../../adaptive-tablet-layout.md).
These images are not physical-device or physical-fold acceptance evidence.

The keyboard and expanded-connection images are focused captures after the
keyboard-pan and cached-grid-span regression fixes. The native interaction
checks verify the pinned header and full-width form, not just image dimensions.
