# v0.11.1 captures

Six fresh captures from the version 0.11.1 / code 36 debug APK, running the actual Compose UI in the debug-only ScreenshotActivity with synthetic usage data. Captured 2026-10-30 on Android API 36.1 with a software renderer.

- `liquid-glass-phone.png`: Usage, light.
- `liquid-glass-dark-phone.png`: Usage, dark.
- `liquid-glass-spend.png`: Trends / Spend.
- `liquid-glass-history.png`: Trends / History.
- `liquid-glass-settings.png`: Settings / Monitoring, including native glass switches. Notification permission is intentionally not granted on the disposable emulator.
- `liquid-glass-tablet.png`: two-pane Usage, 2560 × 1600 / 240 dpi.

Phone captures use 1080 × 2400 / 420 dpi. The installed package was checked for `versionName=0.11.1` and `versionCode=36` before capture. No credentials or live account history are included. These are emulator results; physical-device acceptance is separate. The production APK excludes the debug harness.
