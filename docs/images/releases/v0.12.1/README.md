# v0.12.1 release captures

Real Compose screens from the v0.12.1 / versionCode 38 debug APK on Android API 36.1, captured on a disposable emulator. Quota, history and spend data are synthetic; no account credentials are present. The daily photo and visible photographer credit are from the app's configured Unsplash background. The screenshot activity and fixture data are absent from the production APK.

Phone captures use 1080 × 2400 at 420 dpi; the tablet uses 1920 × 1200 at 180 dpi. `liquid-glass-ordering.png` shows the active inline editor. These captures are emulator evidence, not physical-device acceptance.
