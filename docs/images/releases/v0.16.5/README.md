# v0.16.5 screen references

Six portrait captures from the v0.16.5 debug APK (build 50) on an API 35 emulator.
The window is 412 × 890 dp at 320 dpi with gesture navigation enabled. The
fixture uses the Liquid Glass theme and synthetic account data.

The four tabs show the navigation bar at rest. The Settings captures show the
section icons and the About CodexBar layout, including the version and build
number. The debug fixture is excluded from the production APK.
