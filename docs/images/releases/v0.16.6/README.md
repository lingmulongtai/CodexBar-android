# v0.16.6 gesture reference

The six frames are from one API 35 emulator recording of the Usage-to-Connections
drag. The debug APK contains this release's UI code with the previous version
metadata (0.16.5, build 50). The fixture uses synthetic data and gesture navigation.

Read the images in numerical order, from the resting Usage tab through the hold,
drag and release to the resting Connections tab.
